# 🎵 MusicGuard — Site Oficial & Documentação

Website institucional, central de documentação e tabela de preços do **MusicGuard**.

## 🌐 Tecnologias
- HTML5 Semântico
- Tailwind CSS
- Google Fonts (Plus Jakarta Sans & JetBrains Mono)
- Google Material Symbols
- Hospedagem na Vercel

## 🚀 Estrutura
- `index.html`: Landing page, apresentação institucional, documentação e planos dinâmicos.
- `app.html`: Página de redirecionamento e acesso ao aplicativo desktop.
- `vercel.json`: Roteamento limpo e suporte a URLs canônicas.
